# Agent Note: 独立维护通用规则与可选协作习惯

Status: implemented

本 fork 保留上游文档、决策、检查与预览能力，补充通用代码审查、简化和交付验证选择，并将维护者偏好放入单独的可选配置。使用与来源归[采用说明](../../../../docs/fork-maintenance.md)，具体习惯归[个人配置](../../../profiles/personal.md)。

这个选择部分取代[三技能范围决定](2026-10-15-documentation-only-scope.md)：本 fork 提供六项 Skill，但仍不搬入产品源码、基准目录、框架运行时、上游专属检查或项目实验参数。原决定避免无消费者专项资料与过量接入的理由继续适用；保留的文档技能、暂存快照和冻结保护仍使用既有实现。

仅保持原三项 Skill 的备选维护成本最低，但不能承接已采用过的审查、简化和验证选择方法。把研究项目专用 Skill 直接复制出来会把实验语义和目录承诺误当通用规则；因此从固定的公开 DeepSeek 来源改写，仅保留跨项目的判断方法。归档已由 maintain-decision-notes 承接，不再添加同义技能。

把所有习惯写进全局指令能立即影响每次任务，但会增加常驻内容并改变无关项目；个人配置因此按需迁入，维护本 fork 时显式读取。公开材料只保存已选择的通用表述，私有日志、基础设施配置和项目运行记录留在其所属位置。

代价是需要维护个人增量与上游更新的交叉影响。技能集合检查列出本 fork 的六项入口，UI 元数据与引用一起验证；目标项目按自身集合调整检查，不能直接把本包检查当成业务验证。静态检查不证明技能决策效果；真实使用中的新案例和反例是后续修订依据。当前未对其他项目或全局技能目录执行接入。
